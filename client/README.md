# Quick Order — Totem (Next.js)

Frontend do sistema Quick Order. Veja a documentação completa do projeto no [README raiz](../README.md).

## Scripts

```bash
npm install
cp .env.example .env.local   # preencher NEXT_PUBLIC_API_URL

npm run dev      # http://localhost:3000 (requer a API rodando em NEXT_PUBLIC_API_URL)
npm run build && npm run start
npm run lint
```
